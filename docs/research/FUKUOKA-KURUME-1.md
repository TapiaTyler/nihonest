# Kurume City local guidance research

Inspected 2026-09-25. Kurume City pages were fetched with `npm run local-guidance -- fetch` and read from `.local-guidance/location-kurume/`. The [J-LIS Fukuoka municipal table](https://www.j-lis.go.jp/spd/code-address/kyuusyuu/cms_16114187.html) gives Kurume code `402036` and reading `くるめし`. The [city's population page](https://www.city.kurume.fukuoka.jp/1100keikaku/2010shoukai/3040toukei/toukei.html) reports 298,148 residents on September 1, 2026. Kurume is included at the user's explicit request despite falling below the coverage plan's 300,000 threshold; see [scope check](FUKUOKA-KURUME-SCOPE-1.md).
