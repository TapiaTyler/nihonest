# Tokyo: Tachikawa local guidance, batch 1

Official source inspection: September 24, 2026. Tachikawa City (`jp-13202`) becomes a selectable location in Tokyo's
Tama area (phase G1 of [LOCAL-GUIDANCE-COVERAGE-PLAN.md](../LOCAL-GUIDANCE-COVERAGE-PLAN.md)). This batch adds
supplements for six guides; all remain `needs-review`, and no Japanese translation artifacts were created or changed.
National Pension follows with the other Tama cities once Codex's Tokyo pension work is committed. Researched by Claude
with `npm run local-guidance` (fetch and `verify`).

The consultation page writes hours in kana (「午後4じ」) and as "4pm"; the evidence check now reads both forms, and
ruby readings such as 「午後(ごご)5時(じ)」, so `verify` reports no findings.
