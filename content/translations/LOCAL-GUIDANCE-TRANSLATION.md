# Japanese translation of municipality guidance

Municipality guidance (784 supplements across 112 locations, seven guides each) is translated into Japanese one location at a time. Codex and Claude both draft; Claude checks every Codex draft before it counts as reviewed. English stays canonical, and every artifact stays `machine-translated` until a qualified human reviews it.

## Layout

- English: `src/data/local-guidance/locations/<prefecture>/<city>.ts`.
- Japanese: `src/data/translations/ja/local-guidance/<prefecture>/<city>.ts`, one file per English location, holding only that location's artifacts. `define.ts` holds the shared definitions and prompt revisions; the prefecture `index.ts` files and the root `index.ts` are generated by `sync`.
- Each artifact is path-keyed: `title`, `summary`, `applicability`, `responsible-body`, optional `receiving-office` and `source-format-note`, and `actions.<n>.title` / `actions.<n>.description`. The keys come from `translationSourceFields["local-guidance-supplement"]` in `src/domain/translation/translation-source-fields.ts`. Source titles, URLs, and dates stay canonical English.
- An artifact is current when its `sourceRevision` equals `createTranslationSourceRevision` over the English fields. The site shows only current artifacts; a stale or missing one falls back to English field by field, marked `lang="en"`.

## Who does what

- **Assignments:** the user assigns locations or prefectures to each agent. Work only on assigned locations, and never edit another location's file, `define.ts`, the indexes, or the prompt.
- **Codex** drafts with worksheets and integrates as `codex-drafted`, then reports the locations and every flag.
- **Claude** checks each Codex location: reads every field against the English and the official pages, fixes wording in the location file, then runs `review` to mark the checked drafts `codex-drafted-claude-reviewed`. Claude also drafts with the Claude pipeline (`claude-code-claude-reviewed`) and owns the prompt, `define.ts`, and the decisions below.
- Two agents may work in the same checkout on different locations. Files never overlap, so nothing needs merging. Do not run `sync` while another agent is integrating; it rewrites only the indexes, but run it once, before assignments start.

## Commands

```bash
npm run local-guidance:ja -- status [--prefecture <folder>]
npm run local-guidance:ja -- worksheet --location <id> [--all]
npm run local-guidance:ja -- integrate <draft dir> --generator codex-drafted --model <model>
npm run local-guidance:ja -- check [--location <id>]
npm run local-guidance:ja -- draft --location <id> | --prefecture <folder> [--model opus]
npm run local-guidance:ja -- review --location <id> [--ids a,b]
npm run local-guidance:ja -- sync
```

- `status` lists current, stale, missing, and unchecked Codex drafts per location.
- `worksheet` writes `.local-guidance/translation/<id>.md` with the rules, official residence-status names, protected terms, accepted titles from other locations, each supplement's English, and its official sources with any cached page text from `npm run local-guidance -- fetch`. Drafts go in `.local-guidance/translation/<id>/<supplementId>.json` as `{"fields": {...}, "flags": [...]}`.
- `integrate` checks each draft, computes its revisions, and writes it into its location's file, replacing any earlier artifact for that supplement. Drafts that fail a check are left out and listed.
- `check` runs the mechanical checks on integrated artifacts and reports stale ones. The catalog test in `local-guidance-translations.test.ts` runs the same checks and fails on any stale or failing artifact.
- `draft` is the Claude pipeline: one isolated Claude call per supplement with the prompt, protected terms, and cached official page excerpts, written to `.local-guidance/translation/claude-<time>/` with a summary of problems and flags. Claude reviews and fixes the drafts before integrating them.
- `sync` creates a Japanese file for every English location and regenerates the indexes. Run it after `npm run local-guidance -- add-location`.

## Drafting rules

Follow `JAPANESE-LOCAL-GUIDANCE-PROMPT.md`. The essentials:

1. Translate meaning faithfully; do not add, drop, or update facts. If an official page now differs from the English, keep the English meaning and add a flag.
2. Restore official Japanese names (sections, counters, buildings, programs, forms) from the cited official pages; do not back-translate English names. Flag any name you could not confirm.
3. Keep every number: phone numbers, amounts, times, dates, counts, window numbers. The check rejects a draft that drops one.
4. Use the fixed wording in the prompt for titles and the `source-format-note` sentence, and the protected terminology throughout.
5. Report every flag with the location so Claude can settle it. Source notes (where the official page differs from or adds to the English) go to the English research, not the translation: keep the English meaning.

## Checking Codex drafts (Claude)

For each location: read every field against the English and the cited pages; correct official names, terminology, meaning, and tone directly in the location file; run `npm run local-guidance:ja -- check --location <id>`; then run `review` for that location. Record recurring corrections under "Decisions" so later drafts avoid them.

## Decisions

Add decisions here as they are made, with the supplement IDs that prompted them.

Calibration batch (2026-09-26: Shinjuku, Hachioji, Yokohama, Kawagoe, Naha; prompt revision `2026-09-26-r2`):

- The municipality's own term wins over the standard list (そ大ごみ in Hachioji, 集積場所, 社会保険喪失証明書, ハングル rather than 韓国語 where the page says so).
- Health insurance cards are 資格確認書, 資格情報のお知らせ, and マイナ保険証; never the retired 国民健康保険証 (Naha NHI summary).
- Resident tax in Tokyo's special wards is 住民税（特別区民税・都民税）, not 特別区民税 alone (Shinjuku resident-tax summary); Tokyo cities use 市民税・都民税; elsewhere 市民税・県民税.
- Noon is 正午; 12:45 p.m. may be 午後0時45分. The mechanical number check accepts both.
- Drop romanized Japanese in parentheses; the Japanese term replaces it.
- "Plain Japanese" is やさしい日本語; fiscal years are 2026年度（令和8年度）; apps keep the municipality's spelling (さんあ～る).
- `responsible-body` follows the English body (city, ward, or prefecture), in its official Japanese name.
- Do not add official details the English leaves out, and do not correct the English from the official page. Record them as `SOURCE NOTES:`; most calibration flags were of this kind.

Tokyo wards, batch A (2026-09-27: Adachi, Arakawa, Bunkyo, Chiyoda, Chuo, Edogawa, Itabashi, Katsushika, Kita, Koto, Meguro, Minato, Nakano):

- A ward's English "X City" is its own English name; the Japanese is always the bare ward name (足立区, 北区), never X市 and never 東京都北区, even where the ward's site title adds 東京都. Do not flag the English for this.
- Receiving offices use the section names on the ward's page (高齢医療・年金課国民年金係, 国保資格係), with the building and window in parentheses when the English gives them.
- Drafts need the cited pages: the draft and worksheet commands read every cached page under `.local-guidance/` at any depth. If a source is not cached, fetch it (`npm run local-guidance -- fetch <url> --out .local-guidance/translation-sources`) before drafting.

Tokyo, batch B (2026-09-27: Fuchu, Machida, Nerima, Ota, Setagaya, Shibuya, Shinagawa, Suginami, Sumida, Tachikawa, Taito, Toshima). Tokyo is complete.

- Tokyo's cities use 住民税（市民税・都民税） or 市民税・都民税, and the bare city name (府中市, not 東京都府中市).
- Keep a municipality's own facility and section names even where the English romanizes them loosely (白糸台・西府文化センター, 市役所おもや, くみん窓口, こくほ資格係).
- `receiving-office` is a label, not a sentence: no です at the end.

Remaining regions (2026-09-27: Greater Tokyo, Tokai and Chubu, Hokkaido and Tohoku, northern Kanto, Hokuriku, Chugoku, Shikoku, Kyushu, Nagoya). Everything except Kansai is complete.

- Tax names follow the municipality: 市民税・県民税, 市・県民税, 市県民税, and 市民税・道民税 in Sapporo are all correct where the city uses them.
- Window numbers are written 11番窓口, not 窓口11.
- Where the English title departs from the standard pattern ("Flood preparation in Gifu City"), translate that title faithfully rather than forcing the standard form.
- The number check accepts 24-hour times as 午後, small kanji numerals (第一庁舎), 万 amounts (5万円), and upper ages written with 未満 (20歳以上60歳未満 for "20 to 59").

Kansai (Codex drafts, checked 2026-09-28: Kyoto, Osaka, Sakai, Higashiosaka, Hirakata, Ibaraki, Suita, Takatsuki, Toyonaka, Kobe, Himeji, Amagasaki, Nishinomiya, Akashi). Every planned location is now translated and checked.

- Osaka Prefecture cities use 市民税・府民税 (or the city's own 市・府民税); Hyogo cities use 市民税・県民税.
- In a pension guide, "workplace coverage" is 職場の社会保険 (pension and health insurance together), not 職場の健康保険.
- When the cited page does not name the office the English describes, a descriptive name (住民記録の窓口) is correct. When the English mentions wards in a city without them, the Japanese still follows the English.
